# Piffy Studio Development and Bug Log

## About this record

The historical record below has been reconstructed from the **206 Git commits on `main`**, from 22 November 2025 to 21 November 2026. Related commits are grouped for readability, but each listed hash is an individual commit link. Dates are Git committer dates in UTC.

The log distinguishes bug fixes and issues from feature development and general improvements. Commit messages and code changes are evidence of what was changed; they are not, by themselves, proof that a fix worked. Where the repository does not contain a historical test result, the verification column says **Historical verification unavailable**. The preserved contemporaneous entry below records what the original project log said at the time, including its own manual-verification claim.

| 2025-11-29 | Images would not upload: Django kept returning `No file was submitted` despite files appearing inside `request.FILES`. | Image handling, forms, file uploads | The image upload form was mixed inside the main product form, causing Django to treat file input incorrectly. We separated image upload into its **own independent POST endpoint (`upload_product_image`)**, added a dedicated form with proper `enctype="multipart/form-data"`, and rewrote the view logic so image uploads bypass product validation entirely.
