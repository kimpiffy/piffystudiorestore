NAVIGATION

Oaksun Studio influenced the idea that identity can behave as an interactive part of the interface rather than remaining static. GEMMA CHUANG PROVIDED A USEFUL REFERENCE FOR THE SPATIAL RELATIONSHIP BETWEEN PERSONAL IDENTITY AND THE NAVIGATION SYSTEM. NEITHER FUNCTION EXACTLY LIKE KIM PIFFY’S DESIGN; INSTEAD, THIS SITE COMBINES ASPECTS OF BOTH.

kim piffy uses a conventional information hierarchy but with an expressive visual treatment. Rather than separating the name/logo from the menu, the oversized wordmark anchors the navigation so that the brand identity and interface occupy the same visual space. This avoids unnecessary visual clutter while giving the navigation a stronger role in the identity of the site.
